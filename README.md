# DragonQuest2D
 
This project is a simple, 2D-platform video game. The gameplay consists of side-scrolling, where players control a character that navigates dangerous environments filled with enemies, traps, and challenges. It is mainly inspired by modern platform games, but also includes retro aspects which add a sense of familiarity and nostalgia. The game combines responsive controls, combat mechanics, and interactive environments for a polished and re-playable experience.
